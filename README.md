# ⚡ Tensura Gallery

A fan-made interactive character gallery inspired by **That Time I Got Reincarnated as a Slime (Tensura)**.

This project was built as a frontend side project to experiment with anime-inspired UI, layered layouts, glassmorphism, character cards, and JavaScript interactions.

## ✨ Features

- 🎴 Interactive character gallery
- 🎨 Anime-inspired visual design
- 🖼️ Character-focused hero section
- 🧊 Glassmorphism UI
- 🤖 Mini Rimuru assistant
- 💬 Rule-based responses using JavaScript
- 🔄 Randomized assistant responses
- 📱 Responsive layout
- 🚀 Deployed with Vercel

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Vercel
